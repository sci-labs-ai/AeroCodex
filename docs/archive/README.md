# Historical documentation archive index

Current users should start at the repository README, `docs/research_alpha/cli_formula_quickstart.md`, and `docs/release/v0.1.0-alpha.1-status.md`.

The following retained trees are historical engineering records, not current installation or release instructions:

- `docs/phase_0_001/` — original microtask reports, inventories, and phase audits;
- `docs/beta1/` — the historical Beta 1 concept and compatibility notes;
- `docs/roadmap/` — prior readiness queues, stage plans, and decision packets, except current count/version references explicitly linked from the release status;
- M07 wave-resolution documents under `docs/assurance/` — quarantined source-accounting history, not executable release scope.

Files remain at their governed paths because validation cards, source records, and historical commits reference them. This index moves them out of the user-facing navigation path without rewriting immutable evidence links. Historical statements are point-in-time records and do not override the current release manifest.

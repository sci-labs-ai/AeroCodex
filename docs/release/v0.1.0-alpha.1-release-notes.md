# AeroCodex v0.1.0-alpha.1 — Research Software Alpha

This is the first governed AeroCodex Research Software Alpha release. It provides a reproducible command-line release slice for twelve M00 canonical-unit conversion formulas, along with source, platform binaries, checksums, an SPDX 2.3 SBOM, and project-defined in-toto provenance.

## Supported formula slice

The executable release slice is exactly these twelve formula IDs:

- `m00.angle.deg_to_rad`
- `m00.angle.rad_to_deg`
- `m00.canonical.distance_from_canonical`
- `m00.canonical.distance_to_canonical`
- `m00.canonical.mu_from_units`
- `m00.canonical.speed_from_canonical`
- `m00.canonical.speed_to_canonical`
- `m00.canonical.speed_unit_from_du_tu`
- `m00.canonical.speed_unit_from_mu_du`
- `m00.canonical.time_from_canonical`
- `m00.canonical.time_to_canonical`
- `m00.canonical.time_unit_from_mu_du`

All twelve are `implementation_verified` and executable under `normal_research`. That status means the software implementation, dispatch path, input handling, output envelope, and bounded conversion vectors were reviewed. It does not mean scientific reference validation, operational approval, or certification. The other 140 registry formulas remain `research_required`, blocked, and non-public.

## Install and verify

Download the archive matching the host, plus `aerocodex-0.1.0-alpha.1-SHA256SUMS`, then verify the archive before extracting it. The release includes Linux x86_64, Windows x86_64, macOS x86_64, macOS arm64, and source archives.

After extraction:

```text
aerocodex version --json
aerocodex formula list --executable --json
aerocodex formula run m00.angle.deg_to_rad --degrees 180 --json
aerocodex self-check --json
```

The version response reports the package version, exact Git commit, build target, release profile, channel, and raw release-manifest SHA-256. The executable list contains exactly twelve formulas, and self-check reports 14 passed and 0 failed.

## Status definitions

- `implementation_verified`: bounded implementation evidence exists for the public software path.
- `research_required`: the formula remains outside the public executable slice.
- `normal_research`: public execution is allowed only within the Research Software Alpha boundary.
- `blocked`: public execution fails closed.

## Known limitations and non-claims

AeroCodex is intended to become professional-grade, traceable aerospace research software suitable for academic, laboratory, and agency evaluation. It is not certified for flight, mission operations, habitat safety, medical/life-support decisions, or regulatory approval.

This release does not validate the broader 152-formula registry, promote M07 or life-support formulas, establish physical or experimental validation, guarantee fitness for a particular purpose, or authorize use in safety-critical decisions. macOS artifacts are Tier 2. JSON contracts are stabilized for this alpha slice, but the project remains pre-1.0.

## Upgrade policy

Patch-level alpha rebuilds may correct packaging, documentation, or bounded implementation defects without expanding the formula slice. Any formula promotion, schema-breaking CLI change, safety-boundary change, or dependency-policy change requires governed review and fresh release evidence. Follow-up work belongs to the `alpha.2` backlog only after this release's final artifacts pass post-publication verification.

The release provides a committed lockfile, raw manifest sidecar, archive checksum manifest, SPDX 2.3 SBOM, project-defined in-toto/SLSA-v1-shaped provenance, and GitHub artifact attestations. These records support traceability; they are not certification or a third-party assurance statement.

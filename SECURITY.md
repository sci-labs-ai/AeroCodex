# Security policy

## Supported versions

Security fixes are accepted for the latest published `0.1.0-alpha.x` release and the active release branch. Historical snapshots and unpublished roadmap material are not supported distributions.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Use GitHub private vulnerability reporting at [AeroCodex security advisories](https://github.com/sci-labs-ai/AeroCodex/security/advisories/new). Include the affected version or commit, platform, impact, reproduction steps, and any proposed mitigation. Do not include credentials, personal data, export-controlled material, or third-party confidential data.

Maintainers will acknowledge a usable report, assess scope, coordinate a correction and disclosure window, and publish remediation information appropriate to the alpha channel. No response-time or certification guarantee is implied.

Scientific-model disagreements, formula-validation findings, and documentation corrections are important but are not automatically software vulnerabilities; report them through a normal issue unless public disclosure itself would create a security risk.
